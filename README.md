# סקילים מאוחדים לפי נושא

| `image-generation-branding` | יצירת תמונות ומיתוג | brandkit, imagegen-frontend-web, imagegen-frontend-mobile |
| `ecommerce-store-cro` | חנות אונליין ו-CRO | store-design-cro, shopify-operations, whatsapp-customer-service |
| `copywriting-ads` | קופי ומודעות | ad-vision-writing, meta-ads-analysis, החלקים הכלליים של סקיל הקופי העסקי (מסומן hebrew-dr-source) |

- `skills/` — תיקיות הסקילים.
- `dist/` — ZIP לכל סקיל, להעלאה ל-claude.ai (Settings → Capabilities → Skills).
- כללים שנשמרו: שום מידע לא הושמט מלבד תוכן עסקי או ספציפי לנישה (ולפי החלטות המשתמש); טקסט נשאר בשפת המקור; דוגמאות נישה הוכללו ל-`[placeholders]`; סתירות בין מקורות מתועדות ב-SKILL.md ולא הוכרעו.
